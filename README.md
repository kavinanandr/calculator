# Calculator

A simple, modern, and responsive web calculator built using HTML, vanilla CSS, and JavaScript. It features a clean user interface, basic arithmetic operations, and light and dark mode support.

Designed to provide a straightforward calculating experience while demonstrating the fundamentals of frontend web development.

## Features

- **Basic Arithmetic Operations** – Perform addition, subtraction, multiplication, and division.
- **Interactive Calculator** – Enter numbers and operators using the on-screen buttons.
- **Real-Time Input Display** – View your mathematical expression as you enter it.
- **Clear Display** – Clear the entire input using the `C` button.
- **Delete Last Character** – Remove the last entered character using the `X` button.
- **Decimal Support** – Perform calculations involving decimal numbers.
- **Light and Dark Mode** – Switch between light and dark visual themes.
- **Responsive Design** – A calculator layout designed to adapt to different screen sizes.
- **Error Handling** – Handles invalid expressions and displays an error when a calculation cannot be evaluated.
- **Lightweight and Fast** – No external libraries or frameworks required.

## Getting Started

Follow these instructions to run the calculator locally on your computer.

### Prerequisites

You will need:

- A modern web browser (Chrome, Firefox, Edge, etc.)
- Git (optional, for cloning the repository)

No additional dependencies, package managers, or build tools are required.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kavinanandr/calculator.git
```

**2. Navigate to the project directory**

```bash
cd calculator
```

**3. Open the application**

Open the `index.html` file in your preferred web browser.

Alternatively, if you use Visual Studio Code, you can open the project folder and launch `index.html` using the Live Server extension.

That's it! The calculator is ready to use.

## How to Use

1. Open the calculator in your browser.
2. Click the number buttons to enter a number.
3. Select an arithmetic operator (`+`, `-`, `*`, or `/`).
4. Enter the next number.
5. Press `=` to calculate the result.
6. Use `C` to clear the display.
7. Use `X` to remove the last character from the display.

### Example

To calculate `25 + 15`:

- Click `2`
- Click `5`
- Click `+`
- Click `1`
- Click `5`
- Click `=`

The result will be displayed as `40`.
